# IT Helpdesk AI Chatbot

An AI-powered IT Helpdesk Assistant built using Microsoft Foundry.

## Purpose

The IT Helpdesk AI Assistant helps users troubleshoot common technical problems and provides step-by-step IT support.

## Main Capabilities

- Computer and Windows support
- Software troubleshooting
- Wi-Fi and network support
- Email troubleshooting
- Account and login support
- Password reset guidance
- Printer and peripheral support
- Security and phishing guidance
- Error message troubleshooting
- Step-by-step technical support

## AI Platform

Microsoft Foundry

## Model

GPT model configured in Microsoft Foundry

## Project Status

Initial project setup.

The AI instructions are maintained in Microsoft Foundry.
